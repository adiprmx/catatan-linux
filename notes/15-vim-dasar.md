# 15 — Vim Dasar

Vim sering jadi editor default di server. Mode-nya dua:

- Mode normal (navigasi): `h j k l` gerak, `dd` hapus baris, `/kata` cari
- Tekan `i` masuk mode insert (bisa ngetik), `Esc` balik ke mode normal

Keluar dari vim:
- `:w` simpan, `:q` keluar, `:wq` simpan + keluar, `:q!` keluar tanpa simpan

Kalau "nyangkut" di vim: tekan `Esc` lalu ketik `:q!` + Enter.
