# 01 — Perintah Dasar

Perintah yang dipakai tiap hari di terminal:

- `pwd` — tampilkan direktori posisi sekarang
- `ls` — daftar isi direktori; `ls -la` tampilkan semua termasuk file hidden
- `cd <dir>` — pindah direktori; `cd ..` naik satu level; `cd ~` ke home
- `cat <file>` — tampilkan isi file
- `echo <teks>` — cetak teks ke terminal

Contoh:
```
pwd
ls -la
cd /tmp
cat README.md
```
