# Catatan Linux 📝

Catatan belajar Linux & dasar keamanan dari nol — ditulis PR per PR, satu topik satu PR, co-authored bareng.

## Daftar isi

- [01] Perintah dasar (`ls`, `cd`, `pwd`, `cat`)
- [02] File hidden dan permission
- [03] Pipe dan redirect (`|`, `>`, `>>`, `2>/dev/null`)
- [04] `grep`, `sort`, `uniq`
- [05] `find`
- [06] `file`, `strings`, `base64`
- [07] Enkripsi decoding (`xxd`, `tr`)
- [08] Hexdump dan kompresi (`xxd`, `gzip`, `bzip2`, `tar`)
- [09] SSH & SSH key
